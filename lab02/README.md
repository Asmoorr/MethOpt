# Работа 2. Метод ломаных (Пиявского)

Поиск глобального минимума одномерной липшицевой функции на отрезке.
Алгоритм реализован самостоятельно; NumPy используется для сетки рисунка,
Rich — для таблиц, Matplotlib — для графика, python-dotenv — для чтения настроек.

## Запуск

Из корня проекта:

```powershell
poetry install
Copy-Item lab02/.env.example lab02/.env
poetry run python lab02/src/main.py
```

Копировать пример нужно только при первой настройке. Программа всегда читает
`lab02/.env` относительно своего расположения, независимо от рабочей папки.
Ввод в консоли не требуется. `.env` не публикуется в Git; пример настроек публикуется.

| Параметр | Значение |
| --- | --- |
| FUNCTION | Строка выражения от x, например `x + sin(pi*x)` |
| A, B | Концы отрезка, A < B |
| EPS | Положительная точность по значению функции |
| ESTIMATION_INTERVALS | Число равных интервалов для начальной оценки L, не менее 2 |
| MAX_ITERATIONS | Максимум новых точек после двух граничных |

Десятичный разделитель — точка; возведение в степень — `**`.
Разрешены `+`, `-`, `*`, `/`, `**`, скобки, `x`, `pi`, `e`, а также
`sin`, `cos`, `tan`, `exp`, `log`, `log10`, `sqrt`, `abs`, `sinh`, `cosh`, `tanh`
с одним аргументом. `log` — натуральный логарифм. Функция должна быть конечной,
вещественной и липшицевой на всём отрезке.

## Метод

1. Один раз вычисляются значения на равномерной сетке и
   `L = 1.2 * max(abs((f(x[i+1])-f(x[i]))/(x[i+1]-x[i])))`.
2. Поиск начинается только с двух концов отрезка. Внутренние точки оценочной
   сетки не используются как найденные минимумы или вершины ломаной.
3. Для соседних верхних вершин `(xl, fl)` и `(xr, fr)` вычисляются нижние:
   `t = (xl+xr)/2 + (fl-fr)/(2*L)` и `p(t) = (fl+fr-L*(xr-xl))/2`.
4. Выбирается самая низкая вершина (при равенстве — самая левая).
   Вычисляется `f(t)`, новый интервал разделяется на два.
5. Остановка: `f(t) - p_previous(t) < EPS`. Значение предыдущей ломаной
   сохраняется до вставки точки. Иначе проверка всегда давала бы ноль.

Верхние вершины хранятся по возрастанию x; нижние пересчитываются аналитически
по соседним вершинам. Минимум ломаной не ищется перебором сетки.
Результат — лучшая из вычисленных при поиске точек, включая границы.
Сетка нужна только для первоначальной оценки L и отрисовки исходной функции.

Численная оценка L с запасом 20% не доказывает условие Липшица на всём отрезке.
Статус `converged` означает выполнение критерия с этой оценкой, а не безусловный
математический сертификат. Если новая точка нарушает оценку наклона, программа
завершается со статусом `invalid-lipschitz`, не меняя L. Увеличьте плотность
оценочной сетки и проверьте функцию. Для нулевой оценки используется положительное
`L = min(1, EPS)/max(1, B-A)`; это также не доказывает постоянство функции.
`iteration-limit` означает исчерпание лимита, `stalled` — отсутствие новой
представимой внутренней точки. Для незавершённого поиска код возврата равен 1.

## Результаты и демонстрация

В консоли выводятся новые точки, значение предыдущей миноранты и разрыв,
лучшая точка, статус, L, число итераций и вычислений, время оценки L и поиска.
Две граничные точки переиспользуются из оценки L; их вычисления учтены там.
Время исключает вывод таблицы и построение графика.

`imgs/solution.png` содержит исходную функцию, итоговую ломаную, вычисленные
точки, лучший результат и историю разрыва. Рисунок перезаписывается при запуске.
Отчёт: [Метод ломаных](<report/Трикула метод ломаных.pdf>).

Пример настроен на срез двумерной функции Растригина при y=0:
`f(x) = x**2 + 10*(1-cos(2*pi*x))`, отрезок `[-2, 2]`.
На нём несколько локальных минимумов; глобальный минимум `f(0)=0`, поскольку
оба слагаемых неотрицательны. Даже после попадания в x=0 алгоритм продолжает
строить миноранту до выполнения критерия точности.

Для примера из Excel замените FUNCTION на
`0.5*x+0.2*cos(3.14*x)+0.2*sin(6.28*x)`, A на -2, B на 1.
В Excel формула оценки пропускает крайние разностные наклоны; здесь учитываются все.

- `src/models.py` — задача минимизации, точки, итерации и результат.
- `src/config.py`, `src/expression.py` — настройки и математическое выражение.

- `src/console_tables.py`, `src/plotting.py` — таблицы и рисунок.
- `src/main.py` — последовательный сценарий запуска.

```powershell
poetry run python -m unittest discover -s lab02/tests -v
```

Проверяются пересечение из Excel, выбор минимума предыдущей ломаной,
Растригин, смещённый минимум, минимум на границе, постоянная функция,
лимит итераций, обнаружение недостаточного L и ошибки входных данных.


Решатель получает точность и лимиты в конструкторе. Исходная функция и границы
передаются как OptimizationProblem в solver.solve(problem). Оценка L и цикл
поиска выделены в отдельные методы; история остаётся в Solution.
